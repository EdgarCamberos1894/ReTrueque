# ReTrueque

ReTrueque conecta a personas que ofrecen servicios para facilitar intercambios dentro de la comunidad.

## Despliegues

- Frontend: [https://re-trueque.vercel.app](https://re-trueque.vercel.app)
- Backend (Swagger): [https://retrueque.onrender.com/swagger-ui/index.html](https://retrueque.onrender.com/swagger-ui/index.html)

## Acceso demo

El formulario de inicio de sesion carga estas cuentas con un clic:

- Solicitante: `john_doe@example.com`
- Prestadora: `jane_smith@example.com`
- Contrasena para ambas: `Demo123!`
